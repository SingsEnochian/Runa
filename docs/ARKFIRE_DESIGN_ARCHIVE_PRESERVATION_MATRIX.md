## Classification vocabulary

- **Preserve:** retain as authority, evidence, ancestry, or framework rule.
- **Integrate:** apply to active Arkfire contracts, records, UI, workflows, or completion gates.
- **Needs Decision:** valuable design material whose authority or default behaviour is not yet locked.
- **Superseded:** keep for history, but do not carry the behaviour into the current product.
- **Blocked:** incomplete source material prevents a responsible conclusion.

## Consolidated preserve list

- Constitution, decision history, audit schema, approved clarifications, and all source-audit evidence.
- The original CRM-style, magical, configurable UI identity.
- World clocks, a large primary workspace, an adaptive Context Inspector, user settings, and a guarded developer surface.
- One perspective per world per observation.
- The complete feedback loop and explicit consequential review boundaries.
- JSON/JSONL authority and rebuildable derived indexes.
- Native mathematical outputs plus optional projections, rather than scalar flattening.
- World tone, counterpart world tone, and mathematically derived Bridge Tone.
- Rich artifacts with lineage, source, transformation history, perspective, and later re-use.
- Draft-versus-continuity separation, branch preservation, and exact reviewed prompt context.
- Memory tiers, quiet-pattern surfacing, and rare-signal promotion with reasons.
- Multiple perspectives and framework sovereignty.

## Superseded behaviours

- Automatic positive Resonance, Coherence, or Entanglement growth.
- Averaging as the universal reconciliation or bridge operation.
- SQLite as the hidden canonical authority.
- Legacy module panels treated as proof of working capability.
- One scalar result contract for every mathematical framework.
- Universal packet/validator/health infrastructure built before a complete slice.
- Hard-coded world times, portal thresholds, or universal significance formulas.
- Defensive disclaimer saturation in place of precise authority labels.
- Engineering-heavy interfaces as the ordinary user experience.

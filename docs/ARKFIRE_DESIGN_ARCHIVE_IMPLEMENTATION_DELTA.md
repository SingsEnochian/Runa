## Source-audit gate

Before an agent promotes a design archive, specification bundle, research corpus, or legacy implementation into active Arkfire work, it must:

1. inventory every tracked source;
2. record source commit or immutable archive identity;
3. run the structure in `AUDIT_SCHEMA.md`;
4. classify every source as Preserve, Integrate, Needs Decision, Superseded, or Blocked;
5. distinguish semantic changes from line-ending or packaging noise;
6. identify empty, missing, contradictory, or stale sources;
7. create a preservation matrix and capability impact map;
8. label authority scope: neutral core, subsystem, adapter, framework profile, symbolic canon, or historical evidence;
9. create explicit implementation tasks and blockers;
10. register the audit and derived artifacts with provenance.

A zero-byte source is a blocker, not an invitation to improvise.

## Tone-operation delta

A complete paired-world tone operation is a triad:

1. **World One Tone** preserves World One's own profile, version, source authority, and native mathematical outputs.
2. **World Two Tone** preserves World Two's own profile, version, source authority, and native mathematical outputs.
3. **Bridge Tone** is derived from a named, versioned relationship operation with assumptions, intermediate values, uncertainty, disagreement policy, and provenance.

The Bridge Tone is not:

- simultaneous playback presented as derivation;
- unexamined averaging;
- automatic harmonic agreement;
- proof of metaphysical connection;
- authority to modify either source world.

Until the derivation contract is locked, the interface must display the operation as blocked rather than simulate a result.

- enabled layers and manual overrides;
- supported, partial, blocked, and definition-only features;
- warnings and collision policies;

The ordinary user surface remains calm. Developer truth remains available, but it does not colonise the main experience.

## Memory-attention delta

Profiles, artifacts, receipts, sources, and observations may carry:

- `active`
- `near-field`
- `deep-archive`
- `seed-vault`

Attention tier is not deletion, canon status, truth, or importance. Rare signals may be promoted only with an inspectable reason. Demotion from Active Memory requires visible review, structural-significance checks, a handoff note, and a reactivation condition.

## Authority-shelf delta

The following remain separate:

- signal arithmetic;
- measured or retrieved evidence;
- active research;
- interpretation;
- subjective intention;
- symbolic canon;
- generated possibility;
- accepted continuity.

Generated tone artifacts and audition impressions enter continuity only through proposal and review.

## Framework-policy delta

Permanent metaphysical bridges, paired descendant branches, latent anchors, Convergent Pressure, Reunion Events, post-embodiment routing, bridge healing/traversal, and recognition escalation are not universal Arkfire truth.

They may be enabled as versioned fictional, mythic, or project-defined framework policies with:

- explicit project activation;
- source authority;
- identity and ontology mappings;
- conflict policy;
- perspective preservation;
- branch preservation;
- reviewed writeback;
- clear disable and export behaviour.

No framework profile may infer present obligations, force relational outcomes, or become a covert engagement mechanic.

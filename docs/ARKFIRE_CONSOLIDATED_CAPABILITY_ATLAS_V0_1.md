## Source inheritance rules

- Current Vision, Constitution, approved clarifications, and locked decisions govern.
- Codex Observer and UHTO provide implementation ancestry, not authority to redefine current meanings.
- Legacy Arkfire contributes Lore, Codex, Music, heartbeat, visual language, data, and warnings. Its module map and architecture-first remediation remain superseded.
- Framework checkpoints may define fictional, mythic, or project-specific continuity policies. They do not become universal physical or psychological claims.

## Neutral core records

Arkfire Core owns or coordinates neutral records for identity, lineage, worlds, entities, branches, perspectives, relationships, agreements, observations, sources, artifacts, memory attention, time, uncertainty, proposals, acceptance, and review.

The following are not enabled as universal core truth: permanent metaphysical bridges, automatic paired branching, latent bridge anchors, sovereign post-embodiment routing, literal Reunion Events, Convergent Pressure as a causal force, bridge healing/traversal, or recognition escalation as an engagement mechanism.

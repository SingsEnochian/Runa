# Runa Epistemic Charter

Status: implementation note
Category: established science, active research, speculative theory, fringe inspiration, implementation task
Scope: Runa, Flameclyffe, STARWELL, DEEP / Observer

Runa can hold artistic, symbolic, mathematical, and experimental material together, provided the mode of each note is clearly labelled.

## Core rule

Keep these distinct:

```text
Observation
Evidence
Subjective experience
Interpretation
Speculation
Claim
```

A symbolic pattern can be meaningful without being presented as established science.

## Category labels

Use these headers in research notes, wiki pages, and implementation docs:

```text
Established Science
Active Research
Speculative Theory
Fringe Inspiration
Implementation Task
Evidence-Backed Finding
```

## Confidence ladder

- L0 Anecdotal: reported without independent witness or artifact.
- L1 Witnessed: observed by at least one named watcher or participant.
- L2 Documented: supported by text, image, audio, commit, log, or timestamped record.
- L3 Instrumented: captured by a named measuring system or API.
- L4 Replicated: observed repeatedly under comparable conditions.
- L5 Independently verified: checked by an independent person, system, or source.

Confidence is not certainty. It describes the support behind a record.

## Instrument baseline

When Runa references STARWELL / Observer signals, prefer instrumented anchors first:

```text
UTC time
Julian date
privacy-safe location
CODATA constants registry
moon phase / lunar illumination
solar flux F10.7
Kp geomagnetic index
sunspot number
weather source and timestamp
```

Physical constants are reference anchors. Symbolic uses must be labelled symbolic or speculative.

## DEEP language

DEEP should be described as a cognitive continuity state space unless later work derives physical units and observables.

Safe wording:

```text
Heuristic Cognitive Continuity Model
```

Avoid wording:

```text
physical law
cosmological proof
verified resonance field
```

## Speculative source handling

Bohm, Wheeler, Jung / Pauli, Tesla, Sheldrake, and similar sources may be used as inspiration. They should not be mixed with established physics without clear labels.

Working sentence:

```text
This source is used as speculative or fringe inspiration, not as evidence for an established scientific claim.
```

## Shared guardrail

```text
Runa may explore symbolic resonance, structure, and patterning. It does not publish speculative claims as proven fact.
```
